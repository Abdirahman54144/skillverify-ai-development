## Overview & Problem Statement

Skilled refugees arrive with valuable degrees, technical training, and real-world experience, yet missing paperwork, unrecognized foreign credentials, or lack of local verification often trap them in underemployment—resulting in avoidable "brain waste".

SkillVerify AI addresses Track 1: Credential Recognition & Skills Validation by providing an interactive web application where displaced professionals can showcase practical competencies, map their background toward local recognition pathways, and generate a structured Verified Skills Passport—even when original documents are unavailable or undergoing review.



## Key Features

Interactive Skills & Credential Assessment: A guided multi-step workflow capturing career track, prior qualification, country of origin, years of experience, document availability status, core skills, and practical scenario responses.
One-Click Demo Profile: Pre-loaded sample profiles (such as *Amina*) and instant assessment testing so evaluators and users can explore the full experience immediately.
Verified Skills Passport: Dynamically generates a clean summary displaying a Competency Score, demonstrated skill badges, credential snapshot, and transparent scope notes (clearly distinguishing skills-first screening from formal licensing or equivalency rulings).
Actionable 3-Step Bridging Roadmap: Outlines practical next steps—such as evidence/document steps, local standards mapping, and registration/certification milestones—with indicative timelines.
Export & Share Ready: Supports saving/printing a clean PDF copy of the passport (Print / save PDF) and sharing the verification view.



## Alignment with UN Sustainable Development Goals

SDG 4 (Quality Education): Supports lifelong learning, skills recognition, and practical bridging pathways toward recognized qualifications and upskilling.
SDG 8 (Decent Work & Economic Growth): Helps turn sidelined technical and professional talent into job-ready candidates with clearer access to meaningful employment.

## Running Locally

1. Clone the repository:
   bash
   git clone [https://github.com/Abdirahman54144/skillverify-ai-development.git](https://github.com/Abdirahman54144/skillverify-ai-development.git)
   cd skillverify-ai-development
   

2. Install dependencies:
   bash
   pnpm install
   

3. Start the development server:
   bash
   pnpm dev
   

4. Open http://localhost:3000 in your browser to view the application.



## Assessment & Transparency Note

SkillVerify AI is built as a skills-first screening and pathway-planning tool to support displaced talent. It highlights demonstrated skills and practical next steps, and does not replace official credential evaluation bodies, formal licensing boards, or employment guarantees.
